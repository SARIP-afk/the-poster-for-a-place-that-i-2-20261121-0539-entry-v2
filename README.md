THALASSA — Isle of the Sleeping Whale: a travel poster for a place that does not exist. A dusk sea under a crescent moon, and one landmark — a sleeping whale whose back is an island, with a lighthouse, three pines and two warm windows on it, a little rowboat with a lantern below. The name is set huge across the top so it still reads at thumbnail size.
